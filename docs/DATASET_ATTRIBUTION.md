# Dataset sources and attribution

This document accompanies the complete rendered RGB images, semantic annotations, target masks and route metadata. It records source attribution; it does not grant new rights to third-party material. Software and dataset licenses await the project owner's decision.

| Component | Recorded source / attribution | Distribution status |
|---|---|---|
| Mars terrain | USGS ASC Mars2020 TRN; Fergason et al. (2020), DOI: 10.5066/P9REJ9JN | Preserve product attribution; no blanket CC0 claim |
| Moon terrain | PGDA/LOLA; Barker et al. (2021), DOI: 10.1016/j.pss.2020.105119; Barker et al. (2023), DOI: 10.3847/PSJ/acf3e1 | Product-specific terms require confirmation |
| Lunar assets | Space Robotics Bench contributors | Per-asset attribution; no NASA endorsement implied |
| Rock material | Poly Haven Rock01; Dario Barresi, Greg Zaal, Jenelle van Heerden, Rico Cilliers; recorded CC0 source | Simulated material, not a measured lunar-rock surface |
| Cabin / Astrobee | nasa/astrobee_media, commit 1cb0620121099cc848f5a3db480464188dc91ea3; source README identifies IGOAL ISS Interior | Code licensing does not establish rights to all media |
| Int-Ball assets depicted in the dataset | Space Robotics Bench, commit 16c5250f4359278abca646c2ef89da9e3ab2a747 | Independent rights confirmation pending |
| Labels, route metadata and procedural geometry | Independently developed Space VLA Benchmark project | Owner's licensing decision pending |

These packages contain saved rendered observations and annotations, without the source meshes, textures, model weights or private execution logs. Public distribution of asset-bearing imagery remains subject to the applicable source terms. Original source and acquisition digests are recorded in each scene manifest and route record.
