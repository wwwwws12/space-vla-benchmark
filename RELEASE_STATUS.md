# Public project website and dataset release / 项目网页与数据发布状态

The project website and `dataset-v1.0` dataset Release are public as of 2026-11-08.

- [English project page](https://wwwwws12.github.io/space-vla-benchmark/)
- [中文介绍页](https://wwwwws12.github.io/space-vla-benchmark/index.zh-CN.html)
- [Dataset Release](https://github.com/wwwwws12/space-vla-benchmark/releases/tag/dataset-v1.0): 29 independent ZIPs, 45.24 GB, plus the manifest and SHA256 checksum list.
- [Code repository](https://github.com/wwwwws12/space-vla-benchmark): core source, protocol, frozen splits and numerical results.

The Release assets retain their original bytes, filenames and SHA256 values. Each dataset group contains 300 routes (60 dev + 240 test); the two lightings share 900 unique paired routes in total.

The static website is deployed from `site/dist/` through the manual GitHub Pages workflow. Source changes require a manual deployment after the reviewed commit is pushed.

Authors, affiliations and code/data licenses remain pending owner confirmation. Third-party material retains its attribution and distribution terms; see [asset documentation](docs/ASSETS.md) and [dataset attribution](docs/DATASET_ATTRIBUTION.md).

The public code scope is described in [CODE_SCOPE.md](docs/CODE_SCOPE.md). Original experiment audits and machine-local data remain in the development workspace.
